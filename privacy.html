Política de privacidad

Última actualización: 18 de septiembre de 2026.

Resumen

SocialFlow Innovar es una aplicación de escritorio que se ejecuta localmente en el equipo del usuario. La aplicación procesa únicamente las cuentas y archivos que el usuario decide conectar o importar.

Datos procesados

La aplicación puede procesar identificadores de cuentas, nombres visibles, tokens de autorización, textos de publicaciones, imágenes, videos y fechas de programación. Las credenciales se guardan cifradas mediante la protección del usuario de Windows. La biblioteca y el calendario se guardan localmente.

Servicios conectados

Cuando el usuario lo solicita, la aplicación transmite contenido y los datos necesarios a TikTok, Meta o Google Drive mediante sus API oficiales. Cloudinary es una integración opcional. Cada servicio aplica sus propias políticas.

Uso y conservación

Los datos se utilizan únicamente para importar, preparar, programar y enviar contenido según las acciones del usuario. El operador de SocialFlow Innovar no mantiene una base de datos remota de estos datos.

Control y eliminación

El usuario puede desconectar cuentas desde la aplicación, revocar el acceso desde cada plataforma y eliminar la carpeta local de datos. Puede solicitar ayuda escribiendo a xpressfilmsclips@gmail.com.

Seguridad y menores

La aplicación no está dirigida a menores de 13 años. Ningún método de almacenamiento o transmisión es totalmente infalible; el usuario debe proteger su equipo y sus cuentas.

Cambios

Esta política puede actualizarse cuando cambien las funciones o los requisitos de las plataformas.

Privacy Policy

Last updated: September 18, 2026.

SocialFlow Innovar is a desktop application that runs locally on the user's computer. It processes only accounts and files the user chooses to connect or import. It may process account identifiers, display names, authorization tokens, post text, media, and schedule dates. Credentials are encrypted using Windows user protection, while the media library and schedule remain local. At the user's request, required data and media are sent to TikTok, Meta, Google Drive, or optional Cloudinary through their official APIs. The operator does not maintain a remote database of this information. Users can disconnect accounts, revoke platform access, and delete the local data folder. Contact: xpressfilmsclips@gmail.com.
